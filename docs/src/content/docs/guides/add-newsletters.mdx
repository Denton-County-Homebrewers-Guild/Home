### Update Newletter JSON file

In the <a href="https://github.com/Denton-County-Homebrewers-Guild/Home/edit/main/src/config/newsletters.json" target="_blank">GitHub repository</a> select the `newsletters.json` to edit file
<FileTree>
- src
  - config
    - dchg.code-workspace
    - **newsletters.json**
    - socials.json
</FileTree>

#### JSON sample

The ordering of items in the `json` file is how they will show up on the website.

```json
  {
    "name": "2026 March",
    "url": "https://docs.google.com/document/d/e/2PACX-1vQlFc76FGMIETFAK0oJAIuyKOHoiCDV0sEdx79DcnIsBbi3uYHFoqNsyrY6HC_wj5d8hixxHPfXyMp6/pub"
  },
```

**Action** history can be viewed by clicking the <a href="https://github.com/Denton-County-Homebrewers-Guild/Home/actions" target="_blank">Actions</a> button along the top menu.
