### Adding Images
Add image to the site by placing them under <a href="https://github.com/Denton-County-Homebrewers-Guild/Home/tree/main/originals/images" target="_blank">'originals/images'</a> in an appropriate folder.

<FileTree>
- docs
- originals
  - **images** 
- public
</FileTree>

There is a build process that will optimize the images for use on the website and copy them over
to the 'public/images' folder for us with a *.webp* file extension.

### Making Images Showup

Then go to 'src/config/carousel-images.json' and edit the data file. A sample of an entry from the site is shown below.
Clicking the pencil icon will allow you to edit the file and include entries for new images.
<img width="1087" height="131" alt="image" src="https://github.com/user-attachments/assets/a949de33-6837-4809-ae6d-4346f14ddf0a" />

```json
  {
    "src": "/images/bbo/BBO_2025_DCHG2.jpg",
    "alt": "Keith Green setting up the DCHG bar at BBO 2025",
    "title": "DCHG at BBO 2025",
    "caption": "Keith Green setting up the DCHG bar at Bluebonnet 2025"
  },
```
* src - path to the image. Must match the folder names and capitalization
* alt - text that screenreader use for visually impaired folks
* title - what shows up in the yellow/gold
* caption - the text at the bottom of the display
